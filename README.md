# Trust Legal Group — статическая вёрстка (HTML + CSS)

Чистая семантическая вёрстка сайта Trust Legal Group на HTML + CSS под сборку
**Vite**, подготовленная для импорта в Figma плагином **html.to.design**.
Изначальный проект был экспортом Claude Design (React-SPA, компилируемый Babel
в браузере); здесь он развёрнут в статический HTML с единой системой токенов.

## Запуск

```bash
npm install
npm run dev       # дев-сервер (http://localhost:5173)
npm run build     # прод-сборка в dist/
npm run preview   # предпросмотр собранного
```

Точки входа (multi-page): `index.html` (сайт + блок спецификации состояний под
футером), `styleguide.html` (дизайн-система) и `404.html` (страница ошибки).

## Структура

```
index.html            # страница сайта (13 секций, статический HTML)
styleguide.html       # дизайн-система: палитра, типографика, компоненты
styles/
  main.css            # единый entry — импортирует всё
  tokens.css          # ← все токены (цвет, отступы, радиусы, типографика…)
  reset.css           # сброс
  typography.css      # @font-face (self-host) + классы .text-*
  layout.css          # контейнер, ритм секций
  components/<имя>.css # по одному файлу на компонент
assets/
  fonts/              # Onest + Playfair Display (woff2, self-host)
  images/  team/      # фотографии, логотипы
reference/            # исходный экспорт + извлечённые JSX/CSS (для сверки)
vite.config.js
```

Один компонент — один файл стилей. В разметке — только классы; ни одного
`style`-атрибута. В компонентных стилях — только `var(...)`, без «магических»
чисел (одиночные layout-размеры вынесены в локальные custom-properties).

## Шкалы (см. `styles/tokens.css`)

| Что | Значения | Токены |
|-----|----------|--------|
| Отступы | 2 · 4 · 8 · 12 · 16 · 24 · 32 · 40 · 48 · 64 · 80 · 96 · 128 | `--space-*` |
| Кегль | 12 · 14 · 16 · 18 · 20 · 24 · 28 · 32 · 40 · 48 · 64 (· 80) | `--text-*-size` |
| Межстрочный | целочисленный, на 4px-сетке | `--text-*-lh` |
| Насыщенность | 400 · 500 · 600 · 700 | `--fw-*` |
| Радиусы | 0 · 2 · 8 · 12 · 16 · 24 · pill | `--radius-*` |
| Границы | 1 · 2 | `--border-*` |
| Иконки | 16 · 20 · 24 · 32 · 40 | `--icon-*` |
| Высоты контролов | 40 · 48 · 56 | `--control-h-*` |

Правило округления: `<16px` → к ближайшему кратному 4; `≥16px` → к ближайшему
кратному 8; равноудалённые — вниз. Fluid-значения (`clamp()`) из экспорта сведены
к фиксированным значениям шкалы по опорной ширине **1440px**; для брейкпоинтов
(1023 / 719 / 639) — медиазапросы. `clamp()`, `rem`, модульных шкал и
fluid-типографики в проекте нет.

**Токены — единственный источник значений.** Меняете токен в `tokens.css` —
меняется весь сайт. Все компоненты ссылаются только на `var(...)`.

## Типографика

- **Onest** — весь UI и текст (вес 300–700), self-host woff2.
- **Playfair Display** — вордмарк / редкий serif (500–700).
- **Helvetica Neue** — только первый экран (hero), намеренно, по брифу
  (`--font-hero`). Единственное исключение из основного стека; задокументировано.

Стили текста — переиспользуемые классы `.text-h1`, `.text-body` и т.д.
В разметке ставится класс, размер внутри компонента не переопределяется.

## Импорт в Figma (html.to.design)

1. `npm run build` (или `npm run dev`) и откройте нужную страницу.
2. В плагине html.to.design вставьте URL страницы (или локальный адрес
   дев-сервера) и импортируйте **при ширине окна 1440px** — на неё рассчитаны
   все фиксированные значения.
3. Импортируйте `styleguide.html` отдельно — получите палитру, типо-стили и
   компоненты как основу для Figma-библиотеки.

Структура DOM намеренно плоская (один логический блок — одна обёртка),
раскладка на flex/grid с `gap` → плагин корректно собирает Auto Layout.
Повторяющиеся блоки (карточки, ячейки, пункты) имеют строго идентичную
структуру и классы — из них удобно собирать компоненты.

### Что не переносится в Figma (учитывайте при сверке)

- Страница **статическая, без JS.** Интерактив (меню, аккордеон, карусель,
  раскрытие SEO, отправка формы) не реализован — показаны начальные состояния;
  прочие состояния (`:hover`, `:disabled`, «форма отправлена») продублированы
  статическими классами и вынесены в стайлгайд.
- `position: fixed/absolute` (шапка, мобильное меню, бейджи, водяные знаки),
  `backdrop-filter`, `filter: grayscale` (карта), градиентные скримы,
  `background: linear-gradient` — при захвате могут упроститься.
- Псевдоэлементы с контентом заменены реальными тегами, иконочных шрифтов и
  `background-image` для иконок нет — иконки инлайновым `<svg>`.

## Известные исключения вне шкалы

Задокументированы намеренно (декоративные/одиночные): водяные знаки-номера
`spec-panel__index` (160/96px) и монограммы `team-card__mono` (96px);
высота карты (420px); ряд `min-height` карточек и локальные ширины карточек —
как локальные custom-properties. Подробнее — в комментариях компонентных файлов.
